# Create Prompt: Extract Repeatable Workflow

Purpose
- Guide an assistant to convert a conversation or repeated task into a reusable prompt that generates a `SKILL.md` or other templated artifact.

Core task (what this prompt automates)
- Read a conversation or notes and extract: the core repeated task, implicit inputs, required outputs, success criteria, and decision points. Produce a concise draft prompt and example invocations that can be saved as a `.prompt.md` or used to generate a `SKILL.md`.

Inputs (provide if available)
- `conversation`: full transcript or link to the conversation text.
- `example_files`: optional paths to supporting files (code snippets, issue number, PR link).
- `scope`: `workspace` or `personal` (default: `workspace`).
- `target_artifact`: `SKILL.md` | `.agents/skills/<name>/SKILL.md` | other (default: `SKILL.md`).

Desired output
- A short, actionable prompt that a human or agent can run to produce a `SKILL.md` (or other artifact):
  - One-line summary of the workflow
  - Required inputs (explicit)
  - Output format and path
  - 2 example invocations
  - 3 clarifying questions when ambiguities exist

Tone and constraints
- Be concise and prescriptive; prioritize clarity over verbosity.
- Avoid implementation details unless asked; focus on structure, branching logic, and success criteria.

Template (the assistant should fill):
"""
Task: Convert the conversation into a reusable skill that documents a repeatable workflow.
Context: <short contextual sentence about repo or conversation>
Inputs:
- conversation: <path or paste here>
- supporting_files: [<path1>, <path2>] (optional)
- scope: workspace|personal
Output:
- Draft SKILL.md saved to: <path>
- Draft must include: title, summary, usage, when-to-use, inputs, outputs, workflow steps, decision-points, quality-criteria, examples, clarifying-questions
Success criteria:
- All main workflow steps are present and ordered
- Branching logic captured as simple if/else lines
- At least 2 example prompts included
- Ambiguities listed as clarifying questions
Examples of invocation:
1) "Create a SKILL.md from the conversation at `conversations/issue-45.txt` and save to `.agents/skills/release/SKILL.md`"
2) "Extract a testing workflow from the selected chat message and output a draft SKILL.md"

Clarifying questions (auto-generated when needed):
- What path should the SKILL.md be saved to?
- Who will review and approve the resulting SKILL.md?
- Are there mandatory tools or files that must be referenced in the workflow?
"""

Suggested next steps after running the prompt
- Review the draft `SKILL.md` and answer the clarifying questions.
- Run a smoke-test: apply the skill to a small example conversation and verify output.
- Iterate and finalize placement under `.agents/skills/<name>/SKILL.md`.
